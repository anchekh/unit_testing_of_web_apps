Кроссбраузерное тестирование сайта Habr

Сайт: https://habr.com.

Цель тестирования: Проверка корректности отображения и работы сайта Habr в различных браузерах и на разных устройствах.

Использованные браузеры и устройства:

| Браузер          | Устройство | Разрешение | Результат                      |
| ---------------- | ---------- | ---------- | ------------------------------ |
| Chromium         | ПК         | 1920x1080  | Работает корректно             |
| Mozilla Firefox  | ПК         | 1920x1080  | Работает корректно             |
| Microsoft Edge   | ПК         | 1366x768   | Работает корректно             |
| Chromium Android | Смартфон   | 412x915    | Адаптивность хорошая           |
| Safari iPhone    | Смартфон   | 390x844    | Есть небольшие смещения блоков |

Проверенные элементы интерфейса:
1. Главное меню
2. Карточки статей
3. Кнопки авторизации
4. Поле поиска
5. Адаптивное меню
6. Скроллинг страницы
7. Отображение изображений

Обнаруженные проблемы: 
1. В Safari на iPhone наблюдается небольшое смещение карточек статей при горизонтальном повороте экрана.
2. В Firefox при масштабировании 125% некоторые изображения загружаются с задержкой.
3. На мобильных устройствах длинные заголовки статей иногда выходят за границы контейнера.

```python
from selenium import webdriver
from selenium.webdriver.common.by import By

driver = webdriver.Chrome()

driver.get("https://habr.com")

title = driver.title
print("Заголовок страницы:", title)

search = driver.find_element(By.NAME, "q")
print("Поле поиска найдено")

driver.quit()
```
