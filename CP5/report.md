# Тестирование сайта pikabu.ru

### Пикабу — ведущая российская онлайн-платформа для публикации пользовательского контента, ориентированная на юмор, мемы и развлекательные материалы.

### Данная платформа подходит для тестирования, так как в ней есть множество функций для проведения тестов (проверка аторизации, поиска, перехода на страницы, нажатие на кнопки и т.д.)

# Что было протестировано: 

### 1. Авторизация (Ввод логина и пароля, вход в аккаунт, проверка входа)
### 2. Поиск (Ввод в поисковик необходимого слова, проверка перехода на страницу с нужным контентом)
### 3. Переход по меню сайта (Нажатие на кнопки в главном меню, проверка правильности и работоспособности перехода на страницы)
### 4. Переход на дополнительные страницы (Главная -> Страница из меню -> Страница из выбранной из меню (Главная -> Темы -> IT))

# (1) АВТОРИЗАЦИЯ

### Описание: проверка входа существующего пользователя на платформу с помощью логина и пароля
### Ожидаемый результат: заданные данные (логин и пароль) вводятся в нужные поля ввода, кнопка "Войти" активна и работает, пользователь успешно авторизовывается в системе
### Итоговый результат: совпадает с ожидаемым
``` bash
Авторизация успешна
```

# (2) ПОИСК

### Описание: проверка работы поиска на платформе
### Ожидаемый результат: кнопка поиска найдена и работает, поле ввода активно и работает, заданный текст вводится в нужное поле, поиск успешно реализовывается и пользователь переходит на нужную страницу
### Итоговый результат: совпадает с ожидаемым
``` bash
Поиск выполнен успешно
```

# (3) ПЕРЕХОД ПО МЕНЮ САЙТА

### Описание: проверка перехода на кнопки в основном меню
### Ожидаемый результат: кнопки меню активны и работают, переход на страницы проходит успешно, ожидаемый результат совпадает с действительностью
### Итоговый результат: совпадает с ожидаемым
``` bash
Переход на 'Подписки'
Успешно: https://pikabu.ru/subs
...
Тестирование меню завершено
```

# (4) ПЕРЕХОД НА ДОПОЛНИТЕЛЬНЫЕ СТРАНИЦЫ

### Описание: проверка перехода на дополнительные страницы
### Ожидаемый результат: кнопки/ссылки на дополнительные страницы сайта работают исправно, переход на страницы проходит успешно (Главная -> Темы -> IT)
### Итоговый результат: совпадает с ожидаемым
``` bash
Нажатие на тему 'it'
Успешно: переход на тему 'it' выполнен
Тестирование темы 'it' завершено
```
